# Northline HVAC

A polished HVAC service-experience concept built as a Legacy Network case study.

## What it demonstrates
- A high-trust service brand rather than a generic contractor template.
- A guided booking request that captures useful context.
- Emergency-safe language and human handoff.
- A scripted AI concierge interface for qualification and next-step guidance.

The assistant and booking form are intentionally demo-only: no real customer data is sent anywhere.

Open `index.html` locally or host the repository as a static site.
